| Project | What it does | Built with |
|---|---|---|
| [**PhoneMic**](https://github.com/siddarth1872004/phonemic) | Turns an Android phone into a system microphone for Windows and Linux over Bluetooth, Wi-Fi, or USB. Includes low-latency audio streaming, Opus, noise reduction, voice effects, and a phone soundboard. | C++, Kotlin, CMake, Opus |
